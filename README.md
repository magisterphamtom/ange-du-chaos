# L'Ange du Chaos — système Foundry VTT

Système de jeu pour **L'Ange du Chaos**, le jeu de rôle des éditions Les XII Singes (d'après les romans de Michel Robert).
Développé avec l'autorisation des éditions Les XII Singes. **Le dépôt ne contient pas les illustrations ni les textes du livre** : il faut le livre et le pack d'assets personnel pour le wiki et le contenu. Voir `ETAT.md` pour l'avancement et la liste des tests.

Installation : décompresser le dossier `ange-du-chaos/` dans `Data/systems/`, puis relancer Foundry (Ctrl+Maj+R après une mise à jour).
Vérifications hors Foundry : `node tools/test-calc.mjs` et `node tools/bench.mjs`.
